# Modding tools

- `examples/hardcore`: a complete mod (harder fights, an Ironman mode). Copy it to start your own.
- `tools/pack_mod.sh <mod folder>`: packs a mod of scripts and JSON into `<id>.zip`.
- `tools/pack_art_mod.py <mod folder>`: packs a mod with pictures (icons, textures) through Godot 4.7's import.

The guide is [MODDING.md](../MODDING.md). Paths in it like `tools/pack_mod.sh` are in this folder.
